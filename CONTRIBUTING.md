# Contributing to danvas

danvas is a personal, unofficial fork of [HyCanvas](https://github.com/hyscaler/HyCanvas) by HyScaler. Issues and pull requests are welcome.

- Changes that are useful to HyCanvas in general belong upstream: please open them at [hyscaler/HyCanvas](https://github.com/hyscaler/HyCanvas) (which has its own contributor agreement, see [CLA.md](CLA.md)).
- Contributions to this repository are made under the [Elastic License 2.0](LICENSE), like the rest of the code.
- Before opening a pull request: `npm run lint` and `npm run test` pass, and nothing in the change contains secrets or personal data.
- The architecture rules in [CLAUDE.md](CLAUDE.md) apply, above all the zero-data-loss rules for the design file format and the database.
